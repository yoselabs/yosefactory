Build-time ADRs only. Design decisions live in P160 (D015).

Written when archiving a change that made a non-obvious build-time choice (see
`openspec/config.yaml`'s `operations.archive.guidance` — that is the checked seam, not this file;
this file is the format reference, not the trigger).

Header block, in order: `Status`, `Date`, `Supersedes`, `Superseded by`, `Revisit trigger`. The
last is a single falsifiable, dated observation that would justify reopening the decision — not
"if requirements change." Same field name and bar as K's `revisit_trigger:` on mechanisms.
